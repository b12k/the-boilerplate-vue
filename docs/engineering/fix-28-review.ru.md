# Пункт 28 — порог inline-изображений

Статус: реализован и проверен 11 октября 2026. Пользователь подтвердил отдельный коммит.

В createImageLoader значение parser.dataUrlCondition.maxSize снижено с 256000 до 8192 байт. Изображения размером до 8192 байт включительно остаются data URL; более крупные выпускаются отдельными файлами с content hash. Общий loader используется клиентской и SSR-сборками. Изменение кода — одна строка в rspack/loaders.ts.

Выбор между inline и отдельным ресурсом соответствует механизму [Rspack asset modules](https://rspack.rs/guide/features/asset-module); точная граница подтверждена сборкой установленного Rspack 2.2.8.

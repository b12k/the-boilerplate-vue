# Пункт 18: клиентский polling версии

База: 377576e. Статус: реализовано, проверено и подтверждено пользователем 10 октября 2026 для отдельного коммита.

## Изменение

createVersionService получает Context и logger. Сохраняет исходную версию клиента и проверяет GET /health сразу при start, затем раз в 60000 мс. При различии вызывает location.reload().

При скрытии вкладки удаляет interval. При возвращении выполняет проверку сразу и восстанавливает один interval. Флаг isChecking исключает параллельные запросы. start идемпотентен; stop удаляет таймер и подписку, поздний ответ после stop не вызывает reload.

Отдельный Axios instance имеет timeout 3000 мс. Он не получает сигнал отмены навигационных API-запросов. HTTP-ошибка и тайм-аут логируются; следующий интервал повторяет проверку. /health уже возвращает Cache-Control: no-store.

Подключение находится только в browser.entry.ts. Остановка зарегистрирована для Vue unmount и HMR dispose. Экспорт идёт через barrel services.

Пользователь упростил контракт во время ревью 10 октября: обработчики ошибок чанков, target URL, jitter и sessionStorage удалены. Полная перезагрузка после атомарного релиза получает контекст новой версии; отдельного предохранителя для устаревшего HTML внешнего кеша нет.

## Наблюдения

В BrowserOS neo перевод другого таба на передний план через CDP не меняет document.hidden тестового таба. Пауза и возобновление проверены harness с управляемыми visibilitychange и таймерами; естественное скрытие вкладки в этой среде не воспроизведено.

location.reload сохраняет текущий браузерный URL. Существующий bootstrap затем выполняет router.push из SSR-контекста, где hash отсутствует: fragment исчезает после инициализации приложения. Этот исходный механизм не изменён пунктом 18; query сохраняется.

На Windows использован прежний SWC_NATIVE_BINDING_CACHE. Известное предупреждение Node о deprecated module.register относится к запуску development. Полный UI QA, проверки Piscina и shutdown не повторялись: сервис не меняет их код или оформление.

# Обзор неоднозначных имён

Дата: 10 октября 2026. Проверены исходники src, script-блоки Vue, Nunjucks со встроенным JavaScript, rspack и корневые конфигурации. Оценка учитывает область видимости и реальное назначение значения. Название считается кандидатом, если оно скрывает роль, тип результата, единицу измерения или путается с соседним понятием.

## Как применять

Сначала согласовать имена. Затем менять определение и все consumers вместе. Состояние Pinia, props и HTTP JSON — контракты; их переименование требует проверки SSR serialization, hydration и вызывающих компонентов. Одиночная локальная замена не должна изменять поведение.

Обычные request/response в Express, app/router/head в фабрике Vue, styles внутри компонента, key/value в обобщённом словаре и to/from в стандартном callback понятны из контекста. Переименование таких имён только ради длины не требуется. Обязательные поля внешних API, например signal, data, filename, не переименовываем; уточняем наши локальные переменные и параметры.

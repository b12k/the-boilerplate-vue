# Пункт 2: Request ID вне Context

Базовый коммит: 1788898. Пользователь подтвердил ревью и отдельный коммит 8 октября 2026.

requestId удалён из buildContext. Тип Context выводится из этой функции, поэтому поле также отсутствует в типе, начальном Pinia state и новых RenderResult. Express Request сохраняет requestId; request.log продолжает связывать события с ID текущего запроса.

Существующий genReqId принимает непустой X-Request-ID клиента или генерирует UUID. Заголовок ответа записывается как X-Request-ID. Logger теперь выполняется перед live reload: заголовок применяется ко всем обработчикам ответа, включая development SSE. На cache hit заголовок относится к текущему запросу и не читается из кеша.

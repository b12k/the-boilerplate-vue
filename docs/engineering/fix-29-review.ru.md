# Пункт 29 — Stylelint для Nunjucks

Статус: реализован и проверен 11 октября 2026. Пользователь подтвердил отдельный коммит.

В check:styles добавлено расширение njk. Существующая настройка postcss-html теперь применяется ко всем шести серверным шаблонам при pnpm check. В статических стилях _env.njk исправлены пять пустых строк между правилами; селекторы и декларации не изменились.

Перед динамическим блоком critical CSS добавлен комментарий postcss-ignore. Выражение Nunjucks не является CSS и получает содержимое только при SSR. Комментарий исключает из разбора только следующий style-элемент; остальные стили и style-атрибуты продолжают проверяться. Это документированный механизм [postcss-html](https://github.com/ota-meshi/postcss-html#turning-postcss-off-from-within-your-html).

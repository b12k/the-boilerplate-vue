# Пункт 3: общий CACHE_SALT

Базовый коммит: cf7324c. Пользователь подтвердил ревью и отдельный коммит 8 октября 2026.

В env.ts вычисляется один CACHE_SALT: VERSION из package.json в production, Date.now() при загрузке модуля в development. CacheService получает одно поле cacheSalt для обеих категорий. Префиксы [RENDER] и [CRITICAL-CSS] остаются разными.

CACHE_RENDER_SALT и CACHE_CRITICAL_CSS_SALT удалены из схемы, .env.example и локального .env. CACHE_SALT не является входной переменной окружения: его значение вычисляет приложение. TTL и протокол pending critical CSS не меняются.

## Условия релиза

Версия package.json должна меняться при каждом релизе: повторная версия повторно использует пространство кеша. Старые записи остаются до своего TTL; приложение с новой версией их не читает.

Graceful shutdown остаётся пунктом 10. Эти проверки подтверждают общий CACHE_SALT, а не готовность всех запланированных изменений к production.

Тестовые контейнеры A/B удалены, свежий образ сохранён. Dev восстановлен на localhost:8080 для ревью. SWC cache root задан только в окружении процесса агента; конфигурация приложения не менялась ради обхода прав доступа.
